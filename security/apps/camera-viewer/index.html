Setup and limitations

Configure the verified Xfinity signaling hosts in .env.local. Keep the phone signed in. If a token expires, return to the Xfinity camera list and import again. Importing alone does not open an independent stream; Connect sends its viewing token to the configured Comcast signaling host.

This is a local diagnostic prototype. Independent account login, automatic token renewal, and remote dashboard access are not implemented. Connection status alone does not prove video is playing; decoded frames and resolution come from the browser’s media statistics.
