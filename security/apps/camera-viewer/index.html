Setup and troubleshooting

Configure the verified Xfinity signaling hosts in .env.local and register the Windows sign-in callback as described in the camera viewer README. Account credentials are encrypted for this Windows user. If Xfinity revokes the session, sign in again here. A connected phone is not needed for account mode.

This service runs locally on this computer. Remote dashboard access is not implemented. Connection status alone does not prove video is playing; decoded frames and resolution come from the browser’s media statistics.

Diagnostic fallback only: imports temporary viewing credentials from an authorized ADB phone. These cannot renew themselves.
