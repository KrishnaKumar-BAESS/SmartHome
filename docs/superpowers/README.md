# Historical design specifications

[The June 2026 scaffold specification](specs/2026-06-24-smarthome-scaffold-design.md)
records the initial repository plan, including placeholders and one-time setup
instructions. Its descriptions of “today,” initial Git setup, empty scaffolding,
and the then-pending home app are historical.

For current behavior, use [architecture](../architecture.md),
[development](../development.md), and the [decision index](../decisions/README.md).
Do not rerun the scaffold's Git initialization or create old paths to make the
current repository match that plan.

Keep dated specifications as context. When adding a new specification, make its
status and relationship to implemented work explicit. Shared documentation
standards live in [documentation maintenance](../documentation.md).
